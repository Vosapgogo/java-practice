# Summer

Це навчальний репозиторій, у якому я практикую різні теми з програмування на Java.

Кожна тема лежить в окремій папці в `src/`, а завдання пронумеровані (`ex_XX`).

## Теми

- **Annotations** (`src/annotations`) — створення власних анотацій, `@Retention`, `@Target`, рефлексія, прості валідатори та міні-тестовий фреймворк.
- **Karel / Race** — вправи з бібліотекою `shpp-karel-lib`.
